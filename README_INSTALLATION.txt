BeerpongArena PWA V88 (Demo)

1. Lade den Inhalt dieses Ordners vollständig auf einen HTTPS-Webserver (z. B. eine Testdomain).
2. Öffne die URL zu index.html auf deinem iPhone in Safari. Tippe Teilen > Zum Home-Bildschirm und öffne das Icon.
3. Auf Android in Chrome: Menü > App installieren / Zum Startbildschirm hinzufügen.
4. Die App startet im Standalone-Modus ohne gewöhnliche Browserleiste, soweit Betriebssystem und Browser dies unterstützen.
5. Wenn du Änderungen veröffentlichst, Version des Caches in sw.js erhöhen.

ACHTUNG: Diese PWA ist eine Demo. Daten und Logins werden nicht zentral gespeichert. Offline-Cache kann zuletzt gespeicherte Seiten anzeigen, aber Live-Ergebnisse benötigen einen Backend-Service und Internet.
Zum Test am PC kann der Ordner über einen lokalen Webserver unter http://localhost bereitgestellt werden. Direkt über file:// funktionieren PWA-Installation und Service Worker nicht.
